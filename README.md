# Home Quiz Engine

Домашняя викторина на русском и английском для игры с друзьями в одной Wi-Fi сети.
Организатор создаёт вопросы, ведущий управляет игрой, телевизор показывает задания,
а гости отвечают с телефонов. Приложение работает на компьютере организатора;
интернет во время игры не требуется.

## Быстрый запуск

Нужны Node.js **22.13 или новее** и npm. В каталоге репозитория:

```sh
npm ci
npm run dev
```

Откройте `http://localhost:5173/admin`, создайте викторину и дождитесь **Saved**
и **Ready to play**. Для телефонов и экрана используйте
`http://<LAN-IP-компьютера>:5173`: Vite выводит доступные сетевые адреса в терминале.
Все устройства должны быть в одной доступной друг другу локальной сети.
Компьютер и терминал с приложением должны оставаться включёнными.

## Четыре интерфейса

| Интерфейс | Адрес | Назначение |
| --- | --- | --- |
| Admin | `/admin` | Редактор, Preview, Test Game, импорт/экспорт и история |
| Host | `/host/<roomId>` | Управление конкретной игрой; открывается из Admin |
| Screen | `/screen/<roomId>` | Показ на телевизоре; открывается через Open Screen в Host |
| Player | `/play` или `/play/<code>?lang=ru` / `?lang=en` | Вход по коду или QR и отправка ответов |

`/host` и `/screen` — входные страницы с подсказками; для игры нужна ссылка комнаты.
Показ и звук идут из браузера Screen на компьютере, подключённом к телевизору.

## Проверки для разработки

```sh
npm run test
npm run typecheck
npm run build
git diff --check
```

Тесты, проверка типов и сборка запускаются для обоих workspace: `apps/server` и
`apps/web`. Команды запуска собранной версии и расположение данных описаны
в [инструкции проведения игры](docs/RUNBOOK.md).
