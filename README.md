# Home Quiz Engine

Домашняя викторина на русском и английском для игры с друзьями в одной Wi-Fi сети.
Организатор создаёт вопросы, ведущий управляет игрой, телевизор показывает задания,
а гости отвечают с телефонов. Приложение работает на компьютере организатора;
интернет во время игры не требуется.

## Быстрый запуск

Нужны Node.js **22.13 или новее** и npm. В каталоге репозитория:

```sh
npm ci
npm run dev
```

Откройте `http://localhost:5173/admin`, создайте викторину и дождитесь **Saved**
и **Ready to play**. Нажмите **Open lobby**: в Host появится блок подключения.
Сканируйте **Host** QR телефоном ведущего, откройте **Screen** по его QR или ссылке
на телевизоре/втором компьютере. Гости сканируют один **Players** QR, вводят имя
и выбирают RU / EN перед входом.

При открытии через localhost приложение предлагает локальные адреса Mac,
сохраняя текущий порт интерфейса (обычно 5173). Если адресов несколько, выберите
сеть вечеринки; при необходимости введите адрес Wi-Fi из настроек Mac.
Ссылки localhost для других устройств не показываются.
Все устройства должны быть в одной доступной друг другу локальной сети.
Компьютер и терминал с приложением должны оставаться включёнными.

## Четыре интерфейса

| Интерфейс | Адрес | Назначение |
| --- | --- | --- |
| Admin | `/admin` | Редактор, Preview, Test Game, импорт/экспорт и история |
| Host | QR/ссылка из блока подключения или `/host` + код | Управление конкретной игрой |
| Screen | QR/ссылка из блока подключения или `/screen` + код | Показ на телевизоре |
| Player | `/play` или `/play/<code>` | Один QR; имя и RU / EN выбираются при входе |

`/host` и `/screen` принимают короткий код активной комнаты. Прямые UUID-ссылки
`/host/<roomId>` и `/screen/<roomId>` продолжают работать.
Показ и звук идут из браузера Screen на компьютере, подключённом к телевизору.

## Проверки для разработки

```sh
npm run test
npm run typecheck
npm run build
git diff --check
```

Тесты, проверка типов и сборка запускаются для обоих workspace: `apps/server` и
`apps/web`. Команды запуска собранной версии и расположение данных описаны
в [инструкции проведения игры](docs/RUNBOOK.md).
