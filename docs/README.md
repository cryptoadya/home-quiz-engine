# Карта документации

[Главная страница проекта](../README.md) → запуск и выбор нужного документа.

## Для организатора

Читайте [инструкцию проведения игры](RUNBOOK.md) по порядку: подготовка →
репетиция → Lobby → игра → результаты → резервная копия.
Перед вечеринкой пройдите [проверки реального оборудования](V1_ACCEPTANCE.md#remaining-limits-and-physical-device-checklist).

## Для разработчика

| Порядок | Документ | Какой вопрос решает |
| --- | --- | --- |
| 1 | [SPEC.md](SPEC.md) | Как приложение должно себя вести? Нормативные требования V1 на английском. |
| 2 | [ARCHITECTURE.md](ARCHITECTURE.md) | Где находятся данные и логика, кто управляет состоянием? |
| 3 | [ROADMAP.md](ROADMAP.md) | Какие этапы реализованы и что осталось проверить? |
| 4 | [V1_ACCEPTANCE.md](V1_ACCEPTANCE.md) | Какие проверки были выполнены, когда и с какими ограничениями? |
| 5 | [CODEX_WORKFLOW.md](CODEX_WORKFLOW.md) | Как выполнить конкретную задачу, проверить и оформить её в Git? |

[AGENTS.md](../AGENTS.md) задаёт правила работы в репозитории. Для поведения
источник истины — SPEC; для границ сервисов и состояния — ARCHITECTURE.
При расхождении задачи со SPEC нужно явно сообщить о конфликте.
ROADMAP и отчёты о проверках не меняют требования продукта.

## Исторические материалы

- [Технические заметки по этапам](history/ARCHITECTURE_PHASES.md) — прежнее
  подробное описание последовательных изменений, миграций и протоколов.
- [Отчёты о реализации этапов](history/ROADMAP_PHASES.md) — прежняя дорожная карта
  с результатами проверок отдельных срезов.
- [Phase 0](phases/00-foundation.md) — исходное задание на уже реализованный каркас.

Архив сохранён на английском для сохранения точных исходных формулировок.
Промежуточные ограничения, старые палитры, числа тестов и сообщения о проблемах
относятся к моменту соответствующего этапа. Для текущего устройства используйте
ARCHITECTURE, для текущего статуса — ROADMAP, для результатов аудита — V1_ACCEPTANCE.

В `docs/phases/` сейчас есть только исходный Phase 0. Этот каталог не содержит
задания на каждый реализованный этап и не обозначает текущую задачу автоматически.
