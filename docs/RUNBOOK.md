# Проведение игры

[Карта документации](README.md) · [Требования V1](SPEC.md)

## 1. Запустите приложение

Нужны Node.js **22.13 или новее** и npm. Из корня репозитория:

```sh
npm ci
npm run dev
```

Веб-интерфейс слушает порт **5173**, API — **3001**. Веб-сервер проксирует
`/api` и `/socket.io`, поэтому гости подключаются к порту 5173.
Разрешите доступ из локальной сети в firewall компьютера. Используйте доверенную
домашнюю сеть: API организатора не рассчитаны на публикацию в интернете.
Все ресурсы приложения, темы, QR и загруженные медиа локальные;
интернет нужен для установки зависимостей, а не для игры.

Для запуска собранной версии сначала выполните:

```sh
npm ci
npm run build
```

Затем запустите два процесса в отдельных терминалах из корня репозитория.

Терминал 1 — сервер:

```sh
npm run start -w apps/server
```

Терминал 2 — веб-интерфейс:

```sh
npm exec -w apps/web -- vite preview --host 0.0.0.0 --port 5173
```

Preview использует тот же прокси к локальному API и Socket.IO.
Не закрывайте терминалы и отключите сон компьютера на время игры.

## 2. Подготовьте викторину и проведите репетицию

Откройте `http://<LAN-IP-компьютера>:5173/admin`. Адрес нужной Wi-Fi сети
есть в выводе Vite. На самом компьютере редактор доступен и через localhost.

Создайте раунды и вопросы, заполните RU/EN, задайте правильные ответы и баллы,
загрузите медиа, выберите Default или Halloween. Дождитесь **Saved** и
**Ready to play**. При ошибке сохранения устраните её до открытия комнаты.
Проверьте длинные тексты, изображения и варианты через **Preview**:
RU Player, EN Player, Screen и Host, включая Reveal.

**Start Test Game** открывает настоящую тестовую комнату с обычными правилами.
Используйте реальные телефоны и телевизор, чтобы проверить QR, медиа, ответы,
паузы, переподключение и финал. Тестовая игра исключена из обычной истории.
Preview проверяет внешний вид и не создаёт игровую сессию.

## 3. Откройте Lobby и подключите гостей

1. На Mac выполните `npm run dev` и запомните LAN-адрес из вывода Vite, например `192.168.178.37:5173`.
2. Откройте Admin и нажмите **Open lobby**. Host покажет код комнаты, например `H8VXT`.
3. На телефоне ведущего вручную откройте `http://192.168.178.37:5173/host/H8VXT`.
4. На телевизоре или втором компьютере вручную откройте `http://192.168.178.37:5173/screen/H8VXT`.
5. Гости подключаются к той же Wi-Fi сети и сканируют единственный **Players / Игроки** QR на Screen.
6. На странице входа гости вводят имя, выбирают RU / EN и нажимают **Join**.

Если помните только базовый адрес, откройте `/host` или `/screen`, введите код
и нажмите **Open Host** или **Open Screen**. Для гостей также доступен `/play`
с вводом кода и `/play/H8VXT` с готовой формой входа.
Код всегда открывает текущую активную комнату: после повторного использования
кода это будет новая игра. UUID-адреса сохраняются для внутренней совместимости.

Player QR использует LAN-адрес открытой страницы Screen и текущий порт.
Если Screen открыт через localhost, единственный частный IPv4-адрес Mac выбирается
автоматически. Loopback, `169.254.x.x` и непригодные адреса исключены.
При нескольких частных адресах на Screen доступен компактный выбор **Party network**;
проще открыть Screen сразу по LAN-адресу Mac. Если адрес не найден, откройте
Screen по LAN-адресу из вывода Vite. Host не требует настройки сети.

Подключите компьютер к телевизору кабелем HDMI или настройте привычное зеркалирование.
Screen — страница браузера. До входа гостей проверьте полноэкранный режим и звук.

В Lobby допускается до 30 игроков; повторяющиеся имена отклоняются.
После Join игрок видит имя и ожидание игры; выбор языка больше не занимает страницу.
В компактных **Settings / Настройки** до начала можно изменить имя, а язык —
и во время игры. После изменения языка Settings закрываются; сервер сохраняет
язык в профиле игрока и восстанавливает его вместе с принятыми ответами при переподключении.
Проверьте список участников и нажмите **Start Game**. Этот шаг фиксирует контент,
тему, медиа и состав игроков. После него доступны переподключения существующих
игроков; новые участники войти не смогут.

## 4. Проведите раунды

1. **Start Round** готовит первый вопрос раунда на Host. Screen показывает
   «Следующий вопрос готов / Next question is ready», без текста и вариантов.
2. **Start Question** открывает вопрос на Screen и запускает обязательные медиа без отдельного Play. Медиа с **Play before timer** должны
   завершиться в заданном порядке до начала приёма ответов и таймера.
3. Игрок выбирает ответ и нажимает **Submit**. Засчитывается только ответ,
   принятый сервером; после принятия изменить его нельзя.
4. Reveal открывается автоматически: все участвующие игроки ответили или время истекло.
   Screen показывает только правильные ответы или пары Matching, объяснение и статистику.
5. Перейдите к следующему вопросу, завершению раунда и, если настроено,
   промежуточной таблице результатов. Повторите для следующих раундов.

Ведущий видит правильный ответ и число ответивших, но до Reveal не видит
выбор каждого игрока. Обычные медиа и звук воспроизводятся на Screen;
на телефонах показываются только интерактивные изображения Matching. Варианты
ответов и кандидаты Matching во время ответа всегда остаются на телефонах
игроков, независимо от старых настроек викторины. Host управляет Play/Pause/Restart;
Screen не показывает технические счётчики медиа и имена файлов.

## 5. Разрешайте паузы и переподключения

**Pause / Resume** останавливают и восстанавливают таймер и активное медиа.
Если игрок теряет связь до принятого Submit во время активного вопроса,
игра автоматически ставится на паузу; ведущий выбирает действие:

| Действие | Когда использовать | Результат |
| --- | --- | --- |
| Wait for Player | Игрок переподключился | Продолжение того же вопроса с восстановленным состоянием |
| Continue Without Player | Решили продолжить без игрока; нужно подтверждение | 0 за этот вопрос; возвращение со следующего вопроса |
| Kick | Нужно удалить участника; нужно подтверждение | Исключение из состава и таблиц, отзыв токена во всех вкладках |

Отключение после принятого Submit сохраняет ответ и само по себе не вызывает паузу.
Принятые записи удалённого игрока сохраняются, но он исключён из соревнования.
Kick нельзя отменить переподключением. До Start удалённый гость может создать новую
личность в Lobby: блокировки устройства в V1 нет. После Final Results Kick недоступен.

Игроку нужно возвращаться в тот же браузер: токен хранится в его local storage.
Обновление страницы или повторное открытие восстанавливает личность и принятые ответы.
Избегайте приватного режима. После восстановления Host и Screen получают состояние
с сервера; их отключение не уничтожает сессию.

## 6. Проверьте воспроизведение

Браузер может блокировать autoplay. При блокировке нажмите **Play media**
непосредственно в браузере Screen: нажатие на телефоне Host не разрешает
воспроизведение на другом устройстве. Если Screen подключился после расчётного
конца клипа и ещё не воспроизводил его, нажмите **Replay media** на Screen
или **Restart** на Host. Таймер обязательного pre-timer клипа начнётся только
после локального воспроизведения и завершения. При неподдерживаемом формате
проверьте файл на другом устройстве или замените его совместимым.

Для ручной проверки загрузите локальные фикстуры
`apps/server/src/fixtures/media/sample.mp4` и `sample.mp3`: трёхсекундное
движущееся тестовое видео и тихий тон. Они не добавляются в викторины автоматически.

Play/Pause/Restart управляют медиа; повторное воспроизведение после начала
ответов не сбрасывает таймер. Звук должен идти только из Screen, от одного
аудио/видеоисточника за раз. Проверьте файлы вечеринки на браузере и колонках,
которые будете использовать: наличие формата в списке не гарантирует поддержку
каждого кодека устройством.

## 7. Завершите игру

После последнего раунда откройте **Final Results**, затем **Show Winner**.
При равных баллах игроки делят место; победителей может быть несколько.
**Close room** требует подтверждения, закрывает комнату и освобождает код.

В истории остаются только завершённые обычные игры: дата/время, фиксированные
идентификатор и название викторины, участники и итоговые баллы.
Незавершённые и тестовые игры туда не входят. Закрытие само по себе не считается
завершением игры и не переписывает уже зафиксированный результат.
Закрытые Test Games очищаются при последующем запуске сервера, когда с момента
закрытия прошло не менее семи дней; открытые тесты этим механизмом не удаляются.

## 8. Сохраните данные

По умолчанию:

| Данные | Путь |
| --- | --- |
| SQLite | `data/quiz.sqlite` |
| Медиа редактора | `data/quizzes/<quizId>/media` |
| Зафиксированные медиа игр | `data/sessions/<sessionId>/media` |

Остановите приложение и скопируйте **весь каталог `data`** для согласованной
резервной копии базы и файлов. `QUIZ_DB_PATH` меняет расположение базы;
медиа лежат в соседних каталогах `quizzes` и `sessions` относительно этой базы.
Например, запуск с другой базой:

```sh
QUIZ_DB_PATH=/absolute/path/quiz.sqlite npm run start -w apps/server
```

Экспорт ZIP переносит одну викторину с её медиа. Он не содержит комнаты,
историю и состояние игр и не заменяет резервную копию. Импорт создаёт новую
локальную викторину; неизвестная тема использует Default с предупреждением.

Перед вечеринкой выполните [чек-лист реального оборудования и восстановления](V1_ACCEPTANCE.md#remaining-limits-and-physical-device-checklist).
